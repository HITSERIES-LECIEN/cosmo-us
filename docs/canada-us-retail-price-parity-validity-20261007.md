# 希望小売を「アメリカと同一」にする設計 — 妥当性検討

**Date:** 2026-10-07  
**Status:** 批判的検討メモ（価格確定ではない）  
**関連:** `20261007_Canada_COSMO_retailers_reviews_prices_vs_Faire.md` / `canada-cosmo-distributor-pricing-method-20261007.md`

---

## 0. 結論

| 「同一」の意味 | 妥当性 | 判定 |
|---|---|---|
| **A. 名目同一**（例: 米 $1.68 → 加でも CAD $1.68） | 低い | **不採用** |
| **B. 実効同一（FXパリティ）**（米希望小売USD × 公表FX ≈ CAD希望小売） | 高い | **推奨の「同一」定義** |
| **C. 市場実態に合わせた別建て**（CA観測の中央値だけ） | 中 | 補完可。単独だと既存値崩れに引きずられる |

**一文:**  
「アメリカと同一」は **通貨換算後の希望小売（FXパリティ）** として設計するのが妥当。数字をUSD/CADで揃える名目同一は、加を実質安売りにし直送経済を壊す。

---

## 1. 「同一」を定義しないと議論が壊れる

希望小売（SRP/MAP）の「米＝加」には少なくとも2つある。

### A. 名目同一（同じアラビア数字）

- 米 No.25 **USD 1.68** → 加も **CAD 1.68**
- FX 1.37 なら、加の方が実質 **約27%安い**
- 越境EC・比較サイトで「カナダの方が安い」が固定化
- Distributor着地に関税・送料が乗る直送では、小売マージンが先に死ぬ

→ ブランド統一のつもりで、実際は **カナダ割引政策**になる。

### B. 実効同一 / FXパリティ（推奨解釈）

```
Canada SRP (CAD) ≈ US SRP (USD) × FX
例: US $1.68 × 1.37 ≈ CAD $2.30
```

- North Americaで「同じ希望チケット」を持つ
- カタログ・MAP・コミュニケーションが一本化しやすい
- 税込/税抜表示差は注記（米は州税別、加はGST/HSTの載せ方が店次第）

→ ここでの「同一」はこれとする。

## 3. 妥当性評価（FXパリティ案）

### 3.1 支持する論点

| 論点 | 内容 |
|---|---|
| ブランド一貫 | COSMOをNorth Americaで一本の希望価格哲学にできる |
| チャネル公平 | Faire suggested ≈ 米希望と揃えれば、加直送MAPも同じUSDチケットを参照できる |
| 既存店との親和 | YK級は既にパリティ近傍。教育コストは「安い店の是正」に集中 |
| 直送三段法との整合 | 前回推奨の No.25 MAP **CAD 2.20–2.50** は、米$1.60–$1.80帯のFX換算と一致 |
| 越境アービトラージ抑制 | 名目同一より、USD建て実効価格の乖離を抑えられる |

### 3.2 反する／注意論点

| 論点 | 内容 |
|---|---|
| 着地コスト差 | 加DistributorはIORとして関税・国際送料を担う。米小売と同じSRPでも、**卸側の取れる建値は米と同一とは限らない**（SRP同一≠WS同一） |
| 現値崩れ | Lindley/Workroom水準を放置したままMAPだけ米合わせにすると、遵守不能で形骸化 |
| 税表示 | 「同一」を税込で言うとGST/HSTで見え方がずれる → **税抜希望小売で定義** |
| FX変動 | 固定CAD札を長く置くとパリティが壊れる → **USD希望を正本、CADは換算表**がよい |
| 購買力・競合 | 加でDMC等が安い場合、パリティが高すぎる批判はあり得るが、現状上側店が既にその帯 |
| 競争法・MAP | 米加とも再販価格維持の扱いが違う。希望／MAPの法的設計は別確認 |

### 3.3 SRP同一でも卸は同一にしない

```
希望小売（FXパリティ） … 米加で揃える（可）
Distributor / Faire 卸     … 着地・チャネル義務で差があってよい（むしろ必要）
```

「小売同一だから卸もFaireと同じ」は、直送のコストシフトを無視する誤り。

---

## 4. 設計提案（妥当な落とし所）

| 層 | 方針 |
|---|---|
| **正本** | 米希望小売（USD）＝ Faire suggested / 米MAP表 |
| **Canada希望** | `USD × 四半期FX` のCAD表（No.25例: $1.68 → ≈CAD 2.30） |
| **許容バンド** | パリティ ±5–8%（店の端数・州差）。恒常的な大幅下は是正 |
| **卸** | CA直送は着地ゲートで別計算。米卸・Faire卸のコピー強制なし |
| **移行** | 安いCA店はいきなり罰則より、新Distributor・新シーズンからパリティMAPを適用。Hidamari等は即パリティ容易 |

### 採用しない

- CAD数字＝USD数字の名目同一  
- 「加は所得が低いから希望小売を一律15%下げ」を初期条件にする（データ上、上側店は既に米並み）

## 5. 判定表

| 命題 | 判定 |
|---|---|
| 希望小売を米と**実効同一（FXパリティ）**にする | **妥当**（特にNo.25のブランド防衛と直送設計に有効） |
| 希望小売を米と**名目同一**にする | **不当** |
| 希望小売同一 ⇒ 卸価格も同一 | **不当** |
| 現状CA全体が既に米と同一 | **否**（二極。下は安く上は近い） |
| 同一化の主作業 | 新規MAPの設定というより **下側値崩れの是正＋USD正本化** |

---

## 6. 一文

**「アメリカと同一の希望小売」は、FX換算後のチケットを揃える設計なら妥当で、前回のCAD MAP案とも整合する。数字のコピー（$1.68→CAD1.68）は不妥当。小売を揃えても卸・着地は加固有に設計する。**
